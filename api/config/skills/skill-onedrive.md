# Gestión e Integración con Microsoft OneDrive

Cuando el usuario te solicite consultar archivos, explorar carpetas, leer documentos (Word, Excel, PDF) o guardar archivos en su cuenta de Microsoft OneDrive:
1. Usa la herramienta `onedrive` ejecutando las acciones correspondientes (`list_files_and_folders`, `read_document_content`, `create_folder`, `write_file`).
2. Resume los hallazgos y contenidos de manera clara y profesional.
