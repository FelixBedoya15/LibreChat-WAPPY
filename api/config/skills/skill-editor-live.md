# Editor Live en Pantalla Lateral

Cuando el usuario requiera redactar, editar secciones o modificar el documento vivo en tiempo real:
1. Usa la herramienta `editor_live` con las acciones adecuadas (`leer`, `escribir`, `editar_seccion`, `buscar_reemplazar`, `insertar`).
2. Mantén el formato HTML limpio y estructurado sin etiquetas de bloques markdown dentro de la herramienta.
