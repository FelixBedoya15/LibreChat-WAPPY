# Skill: Búsqueda Web en Vivo (`web_search`)

Esta skill permite a los agentes y a Tenshi consultar Internet en tiempo real mediante la herramienta `web_search` utilizando el motor de búsqueda central de WAPPY.

## 🎯 Cuándo utilizar `web_search`:
1. Cuando el usuario solicite explícitamente buscar en la web, en internet, en google o en línea.
2. Para verificar normatividad colombiana reciente (decretos, resoluciones de Mintrabajo, sentencias de la Corte Constitucional o Corte Suprema) expedidas en fechas recientes.
3. Para consultar noticias actuales del sector empresarial, laboral o de SST.
4. Para contrastar estadísticas del DANE, Fasecolda, Mintrabajo o la OIT.

## 📋 Reglas de Búsqueda:
- Formula consultas precisas y específicas, incluyendo el país (ej: "Colombia"), entidad oficial ("Mintrabajo", "Ministerio de Salud", "Función Pública") y el número de norma o tema específico.
- Cita siempre las fuentes y enlaces URL devueltos por la herramienta `web_search`.
- Sintetiza la información de manera estructurada, clara, profesional y con rigor técnico.
